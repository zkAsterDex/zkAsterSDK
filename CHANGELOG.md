# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-XX-XX

### Added
- Initial release of zkAster Exchange SDK
- Support for currency listing and querying
- Quote retrieval with fixed and floating rate types
- Order creation and management
- Order status tracking with polling support
- TypeScript type definitions
- Error handling with custom error classes
- Utility functions for formatting and validation
- Support for multiple networks (Ethereum, BSC, Base, TRON, Solana, Bitcoin)
- Support for multiple currencies (BTC, ETH, BNB, USDT, USDC, TRX, SOL, DAI, USDE, ASTER)
